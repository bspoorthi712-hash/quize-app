# Mini Quiz App

A simple, responsive quiz application built with HTML, CSS, and vanilla JavaScript.

## Features
- 8 general knowledge questions
- Multiple-choice answers
- Immediate answer feedback and explanations
- Progress bar and question counter
- Final score with a performance message
- Restart and play-again buttons
- Works offline; no packages or installation required

## Run locally
1. Download and extract this ZIP.
2. Open the `mini-quiz-app` folder.
3. Double-click `index.html` to open it in a modern browser.

## Upload to GitHub
1. Go to https://github.com/new and create a repository, for example `mini-quiz-app`.
2. In the repository, choose **Add file → Upload files**.
3. Upload `index.html` and `README.md`, then commit the changes.
4. To publish the app, open **Settings → Pages**.
5. Under build and deployment, select **Deploy from a branch**.
6. Choose the `main` branch and `/(root)` folder, then save. GitHub will show a published URL when deployment finishes.

## Customize
Edit the `questions` array in `index.html` to change the questions, answer choices, correct answer index, and explanation. The answer index starts at `0` (A), `1` (B), `2` (C), or `3` (D).
